## 1. System context

```
┌─────────────┐    HTTPS    ┌───────────────┐
│   Browser    │◄───────────►│ Vercel CDN     │
│  (student)   │   static    │ (edge, no SSR) │
└─────────────┘              └───────────────┘
        │                            │
        ▼                            ▼
┌───────────────┐          ┌─────────────────┐
│  Vite bundle   │          │ dist/*.js/.css  │
│  (all logic)   │          │ (immutable)     │
```

**Boundary policy:** the browser is the entire runtime. No secrets (there is nothing secret), no env vars, no network calls after load except outbound `rel="noopener"` citation links.

## 3. Data flow

```
LocalStorage (never written v1) ◄─── user quiz state (ephemeral)
data.ts (typed, readonly)  ─────► renderers (pure functions)
qna.ts (retrieval) ─────────────► Ask Pablo (score≥1 → answer, else curated fallback)
ledger table (search/filter) ───► Archive (client-side filter only)
```

No telemetry. No cookies. No tracking. Vercel Analytics: **not enabled**.

## 4. Evidence & citation pipeline

Every rendered fact traces to one of:

1. **Part I synthesis** (dossier PDF, print-ready) — its source is embedded part II (raw reports) and part III (V1–V5 verification ledger).
2. **Inline `sourceUrl`** in `data.ts` / `qna.ts` — clickable in UI.
3. **Absolute claims** — anything unverified appears behind an `UNVERIFIED — DO NOT PRINT` flag or is absent.

**Invariant:** `grep -i "TODO\|XXX\|lorem" src/` returns nothing (enforced at review).

## 6. Security model

- **Threat class**: the greatest risk in this project is **epistemic**, not technical: a confident AI voice laundering falsehood.
  - Mitigation: offline retrieval only; sources mandatory; banned quotes fail type-check; refusal fallback present.
- **XSS**: React default escaping; no `dangerouslySetInnerHTML` anywhere; external links carry `rel="noopener noreferrer"`.
- **CSRF/auth**: N/A — no backend.
- **Supply chain**: Vite + React + TypeScript only; dev dep `playwright` for testing (never shipped to `dist`).
- **Legal tripwire**: hosting outside the estate's licence is confined to nominative educational use; no reproduction; no voice.

## 8. Failure modes

| Failure | Behaviour |
| :--- | :--- |
| Retrieval returns nothing | Curated fallback text + six suggested prompt chips |
| Quiz incomplete | "Answer all 12" state — no false-certification |
| Image missing | `loading` natural fail — alt text + link placeholders |
| Clock drift in future phase (2026+) | "Unloanable since 25 Mar 2026" remains historically true — chronology is self-correcting by design |
